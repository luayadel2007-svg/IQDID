## 3. TLS

| البند | التصميم المقترح | المصدر/القرار |
|---|---|---|
| جهة TLS | **TLS-CA TEST منفصلة** عن مرساة الاعتمادات | SEC-06، Enhanced §6 |
| الأسماء | `*.digital-id.test` (نطاق محجوز) — شهادة لكل خدمة، SAN دقيق، بلا wildcard | GR-01، Enhanced §6 |
| الإنهاء | داخل كل خدمة (DR-06 توصية)؛ الـproxy يمرر بالـSNI دون فك | DR-06 PENDING |

| الثقة | الخدمات والمحفظة تثق بـTLS-CA TEST صراحة؛ **ممنوع** `NODE_TLS_REJECT_UNAUTHORIZED=0` أو تعطيل التحقق | فحص آلي مقترح (CHK-ENV-05) |
| العمر | شهادات TLS ≤ 90 يوماً؛ TLS-CA ≤ سنة | مقترح |
| الإنتاج | Web PKI عامة + mTLS داخلي | `[مستقبلي]` |

تثبيت TLS-CA TEST في مخزن Windows الجذري **ممنوع** (يوسع الثقة لكل التطبيقات)؛ تُمرر عبر `NODE_EXTRA_CA_CERTS` للعمليات المعنية فقط — مقترح.

## 4. Linux CI مستقبلاً

- مصفوفة `ubuntu-24.04` / `windows-2022`، Node 22، `npm ci` من lockfile (P-12).
- PostgreSQL 16 مؤقت لكل تشغيل؛ `tools/run_db_tests.sh` + `run_db_mutations.sh`.
- فحص الأسرار (TASK-2) على كل فرع/PR — حالياً في فرع task2 فقط (T-REPO-10، D-13).
- `permissions: contents: read`، إجراءات مثبتة بـSHA (SNT-R05 — BLOCKED سابقاً)، بلا أسرار.
- لا نشر من CI.

## 5. ما يلزم قبل أي إنتاج حكومي `[مستقبلي]`

HSM وحفل مفاتيح، Web PKI، IdP حكومي بـMFA، شبكات معزولة وجدران نارية، WAF، تكرار وتعافٍ من الكوارث، SIEM، اختبار اختراق مستقل، مراجعة قانونية للاحتفاظ، DR-49 مراجعة مختص PKI، وCRL/OCSP (REQ-PKI-06). **هذا التصميم لا يغطي أياً منها تشغيلياً.**
