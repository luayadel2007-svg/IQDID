# تقرير تنفيذ تحديث IQDID

تم تحديث تطبيقي TASK-8 تدريجياً؛ لا تطبيق بديل ولا إعادة بناء. الشيفرة والوثائق والأدلة تحت فرع `integration/crypto-ready-ux`، للمراجعة كمسودة دون دمج.

## التغيير السلوكي

1. تفضيلات المظهر واحدة بين رأس الصفحة والإعدادات، مع فاتح/داكن/تلقائي يستجيب لتغير النظام. حجم النص والشفافية يحفظان محلياً. حركات 220–240ms وReduced Motion وSkeleton ومعالم تركيز/تجاوز محتوى. الزجاج محصور بشريط التنقل؛ القيم والقرار على خلفيات صلبة.
2. رموز SVG مشتركة للتنقل بدلاً من رموز emoji المختلفة، مساحات وظلال وتدرج كحلي. تمت إضافة اختصار مفضل فعلي في الرئيسية لكل تطبيق، يحفظ مساراً من قائمة مسموحة فقط.
3. المواطن يرى القيم الاصطناعية المحددة قبل الموافقة؛ الخادم يستعمل دالة الإسقاط نفسها. عند تعذر المعاينة أو عدم نشاط الاعتماد تتعطل الموافقة ويظل الرفض متاحاً. لا تُرسل القيم إلى المؤسسة قبل الموافقة.
4. اختيار قالب الطلب غير الحساس يُستعاد من sessionStorage؛ نص الغرض والقيم الشخصية لا يحفظان في تفضيلات العرض.
5. فشل تحميل المؤسسة يعرض خطأ وإعادة محاولة في جميع مسارات المتحقق، بدلاً من إظهار قائمة جلسات فارغة. الخلل كُشف باختبار انقطاع الاتصال.
6. منافذ مستقبلية منفصلة، ونتائج Demo لا تقبل ترقية عبر حقول إضافية أو حالة بروتوكولية في استجابة HTTP. إعداد نقل مجهول يفشل مثل real غير المهيأ.

## الملفات

المسارات الباقية وTyped API لم تستبدل. الملفات الرئيسية:
- `packages/ui/src/{styles.css,hooks.ts,preferences.tsx,Icon.tsx,FavoriteShortcut.tsx}`؛ المكونات العامة القديمة محفوظة.
- `packages/shared-types/src/{index.ts,verification.ts}`؛ حدود DTO ثابتة ونتائج بروتوكولية منفصلة.
- `packages/api-client/src/{transport.ts,crypto-ports.ts}`؛ ملف منافذ الخادم لا يصدر كتنفيذ من نقطة دخول المتصفح.
- `apps/wallet-web/src/pages/RequestDetailPage.tsx` و`packages/mock-services/src/store.ts`؛ دالة `previewDemoDisclosure` مشتركة.
- `apps/verifier-web/src/{gateway.tsx,App.tsx}`؛ OrgBoundary.
- `test/{crypto-contract.test.ts,provider-replacement.test.tsx}` و`packages/ui/src/preferences.test.tsx`؛ اختبارات الحدود والاستبدال والتفضيلات.

أعيد استخدام TASK-3C adapter وTASK-2 scanner بايتياً من رأسيهما المقروءين. لا تعدل نتائج SDK_RAW ولا بوابات G1a/G1b. التبعية الجديدة الوحيدة هي `axe-core@4.10.3` للاختبار؛ لا SDK crypto أو framework جديد. استثناءات lint محدودة بالشيفرة التاريخية المنسوخة، لا تخفيف لقواعد التطبيقات.

النتائج المفصلة وحدود التغطية في [TEST_EVIDENCE.md](TEST_EVIDENCE.md). التحديث لا يطبق تشفيراً حكومياً؛ المنافذ وعقود الاستبدال تقلل مواضع التغيير المستقبلية، ولا تلغي العمل التشغيلي والهجرة والمراجعة.
