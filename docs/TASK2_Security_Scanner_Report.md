## التغيير المحدود

- tools/secret-scanner.mjs: واجهة محمية تحجب stderr الداخلي والإطارات البرمجية عند انهيار المحرك، وتتحقق من مخطط التقرير ورمز الخروج.
- tools/lib/secret-scanner-engine.mjs: محرك Node built-ins فقط، يقرأ Git Index بواسطة أسماء NUL وGit blob IDs، دون تعديل الملفات أو Index. الفحص الافتراضي للملفات staged الجديدة والمعدلة والمعاد تسميتها؛ المحذوفة مستثناة؛ --all-index للفحص الكامل في CI.
- .security/secret-scanner-rules.json: سياسة مقيدة ومقروءة من Index نفسه، دون استثناءات شاملة. يدعم PEM/SSH/PGP، JWK/JWKS الخاصة، أنماط الرموز والاعتمادات، .env، والهوية والوثائق والاتصال ضمن سياق حقول محدد.
- .githooks/pre-commit وtools/install-secret-hook.mjs: تثبيت repository-local فقط، يرفض استبدال Hook سابق أو إعداد hooksPath متعارض، ويحافظ على إعداد المستخدم العام.
- tools/test-secret-scanner.mjs وtools/verify-task2-integrity.mjs: اختبارات Git حقيقية والتحقق من G1.
- .github/workflows/task2-secret-scanner.yml: PR عادي وpush لفرع TASK2، read-only contents، بلا project secrets أو credentials محفوظة أو npm install، إجراءات مثبتة بتجزئات commits، Linux وWindows.
- docs/Secret_Scanner_Policy.md: القواعد، التشغيل والتثبيت على Linux وWindows PowerShell 5.1، والقيود.

لم تتغير التبعيات أو package.json أو إصدار التشغيل المعتمد لخط الأساس. لا توجد أداة طرف ثالث في المحرك ولا تبعيات npm جديدة. استُخدم actionlint 1.7.12 المرخص MIT كأداة تشخيص مؤقتة خارج المشروع، مع التحقق من checksum الرسمي.

## سياسة النتائج والملفات

PASS=0، سر مكتشف FAIL=1، فحص متعذر BLOCKED=2. التقارير تحتوي المسار المنقح ونوع المخالفة ورقم السطر فقط؛ لا تعرض قيم الأسرار. توجد حماية إضافية لأسماء الملفات المحتوية على رمز أو رقم حساس. تعطّل القراءة، غياب Git، انهيار المحرك، الملفات الثنائية غير المدعومة، الملفات الكبيرة، السياسة غير الصالحة والمراحل المتعارضة في Index لا تعتبر نجاحاً.

UTF-8 وUTF-16 BOM مدعومان. ZIP stored/deflate يُفحص دون استخراج، مع CRC واتساق السجلات ومنع orphan records والتشفير وZIP64 والمسارات الخطرة. الحدود: 2 MiB للملف/العضو، 32 MiB expanded، 2000 مدخل، عمق أرشيف 2. الملفات غير المدعومة BLOCKED. الحدود والقواعد موثقة في السياسة.
