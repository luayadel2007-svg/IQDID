# IQDI_BRAND_ASSET_REGISTER

Every brand file, what it is for, and how it was produced.

- **Masters:** `assets/branding/*.svg`, generated by `tools/branding/generate_brand.py`.
- **Derivatives:** PNGs rendered from the masters in Chromium by `scripts/brand-assets.mjs --png`. None is hand-edited.
- **Versions:** the SHA-256 prefixes identify the committed files.

## Where each file is used

| File | Used by |
|---|---|
| `iqdi-app-icon.svg` | `IQDIBrand variant="symbol"`: the header of both apps, through `BrandMark`. Also copied as `apps/*/public/favicon.svg` |
| `iqdi-mark-original.svg`, `iqdi-mark-dark.svg` | `IQDIBrand variant="mark"`: the About cards in both apps' settings |
| `iqdi-logo-original.svg`, `iqdi-logo-dark.svg` | `IQDIBrand variant="logo"`: wallet `/welcome` |
| `png/iqdi-logo-*-512.png` | `README.md` header (`<picture>` with a dark source) |
| `apps/wallet-web/public/icons/*` | `manifest.webmanifest` and the `apple-touch-icon` link |
| Monochrome, `iqdi-icon-small.svg`, the other PNG sizes | Not used by the apps. Delivered for documents, print starting points and other placements |
