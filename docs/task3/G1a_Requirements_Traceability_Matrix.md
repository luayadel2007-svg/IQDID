## مرجع P-04 والمواصفات المثبتة

- P-04 = أمثلة SD-JWT VC draft-ietf-oauth-sd-jwt-vc-19، وليس أحدث مسودة ولا اختبار إنشاء داخلي. النص الرسمي متاح: https://www.ietf.org/archive/id/draft-ietf-oauth-sd-jwt-vc-19.html . تم فتح المرجع، ولم تُنفذ متجهاته في TASK-3.
- Token Status List: draft-ietf-oauth-status-list-21؛ typ=statuslist+jwt؛ ES256 و2 بت ضمن خط الأساس. لا ترقية.
- OpenAPI 3.1.0 بقي كما هو؛ v1.1.0-draft هو إصدار عقود المشروع، وليس إصدار معيار OpenAPI.
- مكتبات OpenID4VP/OpenID4VCI مثبتة في Baseline §2؛ إصدار بروتوكول OpenID4VP 1.0 مذكور في العقد، لكن لا توجد هنا حزمة DR-13 تثبت كل أقسام المواصفات النهائية أو HAIP. لا يجوز استنتاجها من رقم مكتبة.
- baseline يوصي بحذف @sd-jwt/crypto-nodejs، لكن القفل المجمد يحتفظ به؛ لم نغيّر القفل.

## قائمة DR-13 السباعية عشرة

لم تظهر أسماء البنود في المستودع الأساسي أو main أو الملفات المرفقة، بما فيها ZIP المتداخل. يوجد ذكر العدد فقط. لذلك الحالة للقائمة بأكملها SOURCE MISSING، ولا توجد صفوف مختلقة. المطلوب: API_Contracts/Enhanced_Architecture أو جدول DR-13 الأصلي الذي يوسم البنود [غ].
